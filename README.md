# CPlusPlusThings-Guide

《C++ 那些事》（[Light-City/CPlusPlusThings](https://github.com/Light-City/CPlusPlusThings)）的**导学与学习手册**。

原仓库是 95 张「知识点卡片」（面试向）：素材极好，但**结论多半对、推理经常错**，且没有体系。本仓库把卡片串成「**公理 → 定理**」的底层模型，并配套一套**可实测、可证伪**的学习方法——所有结论都附实测命令与真实输出，不是转述。

> 定位：不看它是为了「通过面试」，看它是为了「**能读懂、修改、审查 C++ 代码**」，尤其是 AI 生成的代码（CAE/EDA 仿真软件方向）。

## 核心方法（一条就够记住）

> **任何结论先当「假设」，不当「事实」——先写预测，再实测，再和解释对账。**
> 用 `g++ -std=c++17 -O2 -S`、`nm -C`、`-fdump-lang-class=-`、`-fsanitize=address,undefined`、`-flto -Wodr`
> 就能把 90% 的「看起来权威」的说法亲手证伪或证实。详见 `auxiliary/05-实验工具箱.md`。

## 使用约定

1. 只信原仓库的「代码」和「现象」，对「解释」保持怀疑（`auxiliary/06` 是实测过的错误清单）。
2. 每个主题学完必须留下三行笔记：**原则 / 前提 / 反例**。
3. 本仓库所有技术结论都标注了实测环境，涉及布局/汇编的结论换平台需重测。
