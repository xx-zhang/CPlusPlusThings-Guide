### 1.2 T1-T12 一页速查（推出自 / 一句话 / 失效前提）

| # | 推出自 | 一句话 | 失效前提（关键） |
| --- | --- | --- | --- |
| **T1** | A3+A4 | cv 限定是**类型**属性（const 成员函数 = `const T* const this`） | 顶层 const 不进签名；`volatile` 是另一回事 |
| **T2** | A3+A5 | 生命周期决定析构时机 | 全局 static 跨 TU 顺序未指定 |
| **T3** | A3 | 引用是**别名**，不是对象 | 生命周期延长只在「直接绑定临时对象」句型成立 |
| **T4** | A3+A5 | 拷贝=复制、移动=窃取 | 有析构 ⟹ 移动被隐式删除；拷贝消除（C++17）会省略拷贝 |
| **T5** | A4 | 分派三层：重载/模板/虚函数 | 能证明动态类型时被去虚化（`final`/LTO） |
| **T6** | A1 | 定义位置决定链接性 | 类内=隐式 inline；类外按普通规则 |
| **T7** | A4+T3 | 值类别+引用折叠 ⟹ 完美转发 | `const` 上 move = 拷贝 |
| **T8** ★ | A4+T1+T7 | 类型是**编译期代数**（限定/推导/转换） | 运行期无类型代数（那是 T5） |
| **T9** ★ | A1+A5+T1+T4 | **接口即契约**（类型/所有权/异常/ABI/时序） | 契约只在双方遵守时成立，无运行时强制 |
| **T10** ★ | A2 | 求值有**顺序模型**（单线程的 happens-before 原型） | 实参顺序**未指定**；不诊断 ≠ 有定义 |
| **T11** ★ | A2+A3 | 抽象机**必须落到真实机器**（ABI） | ABI 是约定；不同 ABI 二进制不可混用 |
| **T12** ★ | A3+T2+A5 | 程序有**生命周期**（跨 TU 顺序未指定） | 函数内 static 线程安全是 C++11 起 |

★ = 本轮为补齐骨架新增（`01` 第 2 层）。

## 1.6 · 环境指纹与证伪手段（抗腐化的两件）

**A. 环境指纹**（所有实测结论绑定此环境；变了就要重测）：

```text
平台 : x86-64 Linux, Itanium C++ ABI
编译器: g++ 14.2.0 (Debian) / clang++ 19.1.7
标准 : g++ 支持 c++11/14/17/20/23（本体系以 c++17 为主，个别处注明 c++20）
工具 : nm/objdump/readelf/c++filt/gdb/perf/valgrind/strace 可用；llvm-mca 需另装
        TSan 需 `setarch -R` 绕 ASLR；perf 硬件计数器本机不可用
```

**换环境必须重测的结论（ABI/实现相关）**：`sizeof`/偏移/EBO · vtable/vptr 布局 · 名字修饰 · 去虚化形态 · 内联行为 · 未初始化/越界的具体报错文本。
**换环境*不需*重测的（语言规则）**：ODR/链接性 · 值类别 · UB 定义 · 顺序模型（T10）· 初始化规则。

**B. 证伪手段（每条定理的最小验证命令；完整命令见 `05`）**：

| 定理 | 一行证伪（在 /tmp 建文件后跑） |
| --- | --- |
| T4 | `printf 'struct D{int v;D(int);D(const D&);};\n' ` 用计数器类看 vector 扩容是 move 还是 copy |
| T5 | `g++ -O2 -S` 看 `call_final(Sealed&)` 是否变成 `movl $N,%eax` |
| T6 | 头文件写普通函数，两 TU 编译 → `multiple definition`；加 `inline` → 通过 |
| T8 | `int c{3.9};` → 硬错误；`double d; int b{d};` → `-Wnarrowing` |
| T10 | `printf("%d %d", i++, i++)` 与 `f()+g()` 观察顺序差异 |
| T11 | `sizeof` + `-fdump-lang-class=-` 看布局/虚表 |
| T12 | 换链接顺序 `g++ g2.cpp g1.cpp` → 观察 `B ctor reads A=0` |

**C. 过期清单格式**（待建，用于「演化」维）：
