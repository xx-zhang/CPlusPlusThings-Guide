## 1 · L1 必背清单（第一批）

### 1.1 五条公理（一字不差地记住，这是全部推导的起点）

```text
A1 翻译单元公理：编译器一次只看到一个 .cpp 预处理后的结果，永远不知道别的 TU 里有什么。
A2 抽象机公理：语义定义在抽象机上；UB = 程序在抽象机上没有任何行为定义（不是"结果随机"）。
A3 对象模型公理：对象 = 存储 · 生命周期 · 类型 · 值，四个属性彼此独立。
A4 分层公理：名字/类型/重载/模板/布局全部是编译期的；运行期只剩 值 + 一次 vptr 跳转 + 字节。
A5 资源公理（RAII）：资源绑到对象生命周期上，析构函数 = 被编译器强制的 finally。
```

### 1.2 七条定理钩子（只背这句话 + 挂靠点）

| 钩子 | 挂靠 | 失效点（前提） |
| --- | --- | --- |
| T1 cv 限定是**类型**的属性，不是值的属性 | A3/A4 | ——（const 成员函数 = `const T* const this`） |
| T2 生命周期决定析构时机，析构时机决定安全 | A3/A5 | 全局 static 跨 TU 顺序不确定 |
| T3 引用是**别名**，不是对象 | A3 | 生命周期延长只在「直接绑定临时对象」句型成立 |
| T4 拷贝=复制语义，移动=窃取语义（move 后源对象「有效但未指定」） | A3/A5 | 有析构 ⟹ 移动**被隐式删除** |
| T5 分派三层：重载 / 模板 / 虚函数，只有虚函数花运行期（一次间接跳转） | A4 | 编译器能证明动态类型时会被去虚化（`final`） |
| T6 成员函数**定义位置**决定链接性（类内=隐式 inline） | A1 | —— |
| T7 值类别 + 引用折叠 ⟹ 完美转发（`std::move` 不移动，是 `static_cast`） | A4/T3 | `const` 上 move = 拷贝 |

### 1.3 三条元原则

```text
元1 零开销抽象：不用不付费；用了不比手写慢。（UB 就是给优化器留白换来的）
元2 显式优于隐式：能用类型表达的约束，不要用注释/约定表达。
元3 编译期优先：能编译期算的，不要留到运行期。
```

### 1.4 三把尺子 + 四元组（必背坐标）

```text
三把正交尺子（都是"名字/内存"的不同维度，互不相关）：
  作用域 = 源码哪里能写出来     链接性 = 别的 TU 能不能看见     存储期 = 内存活多久
对象四元组（审代码定 bug 用）：
  存储（哪/多大）· 生命周期（活多久）· 类型（怎么解释字节）· 值（装了什么）
```

### 1.5 符号表（必背，查链接错误最快的方法）

```text
T/t  代码符号（大=外部链接，小=内部链接）      ← 同名两个 T = multiple definition
W/w  弱符号（inline/模板/constexpr/类内成员）   ← 同名多个 W = 链接器合并
R/r  只读数据（大=外部如 C 的 const，小=内部如 C++ 的 const）
D/d  已初始化数据   B/b  未初始化数据（BSS）
U    未定义引用（需要链接器去找）             ← undefined reference 的线索
u    GNU unique（C++17 inline 变量；与 U 完全不同！）
V/v  弱对象
```

### 1.6 关键约定清单（背！这些是推不出来的历史遗留）

```text
· static 的三个无关含义 = 在三个不同位置各改一格（存储期/链接性/归属）
· 函数内静态变量：惰性初始化 + C++11 起线程安全；全局静态：跨 TU 顺序不确定
· vector<bool> 是位压缩的位集，不是 bool 数组
· template<class T> 和 template<typename T> 等价（历史双拼写）
· 字符串字面量 → char* 被禁（ISO C++），但 g++/clang 只告警不报错
· 命名空间作用域 const 默认内部链接（C 里是外部链接！）
· 位域布局、int 大小、sizeof 的单位：实现定义，不背，用 05 实测
```

### 1.7 危险信号清单（= 常见 UB，背成「瞬间检查项」）

```text
① 有符号整数溢出（int 循环计数、x+1>x 的优化把戏）
② 数组/vector 越界（operator[] 不检查！）
③ 悬垂指针/引用（返回局部引用、成员引用绑临时量）
④ 读未初始化值
⑤ strict aliasing 违反（reinterpret_cast / union 类型双关）
⑥ data race（C++11 起是 UB，不是"结果不确定"）
⑦ 未定义求值顺序（i = i++ + ++i）
⑧ 非法移位（移位 ≥ 宽度、负数移位）
```

> 记忆法：**「溢、界、垂、初、别（aliasing）、竞、序、移」** —— 八个字，对应上面八条。

### 3.2 本会话已实测、可直接入档的第一批（全部有真实输出）

| 主题 | 实测结果（一句话） | 挂靠 |
| --- | --- | --- |
| const vs `#define` 拷贝 | 两个 TU 各写 `const int c`（1 和 2）链接通过、各用各的 → **内部链接，每份一份**；`-O2` 下 const 也是立即数 `movl $42` | A1 |
| C vs C++ 的 const | C 的 `nm` 显示 `R c`（外部链接=multiple definition），C++ 显示 `r c`（内部） | A1 |
| `inline` 的真语义 | 同一函数两 TU：普通 → multiple definition；加 inline → 链接过；`nm` 显示 `W` 弱符号；未写 inline 的函数 `-O2` 照样内联 | A1/T6 |
| `inline` 变量符号 | C++17 `inline std::string g_name;` → `nm` 显示 `u`（GNU unique），**不是** `W` | A1 |
| `static` vs `inline` 地址 | 3 个 TU：`cnt_static()` 三个不同地址，`cnt_inline()` 同一个地址 | A1 |
| 类内 `static const int` 取地址 | `&A::k` → `undefined reference to 'A::k'`（类内给值，不给定义） | A1 |
| volatile 做同步 | 2 线程各 20 万次 `v = v + 1`：volatile int 三局丢成 212561/329722/226264；atomic 与 mutex 恒为 400000 | A2 |
| x86 的 `int++` 陷阱 | 裸 `int++` 三局全对（x86 单条 `addl` 指令天然原子），**但仍是 UB**——"跑对了"不能证明无 race；TSan 能抓到 | A2 |
| TSan 使用 | 默认报 `FATAL: unexpected memory mapping`；**用 `setarch $(uname -m) -R ./prog`（关 ASLR）可修复** | A2 |
| noexcept 里抛异常 | `terminate called after throwing`；编译器直接告警 `-Wterminate` | A5 |
| 栈展开中析构抛异常 | `terminate`；g++ 提示「C++11 起析构默认 noexcept」 | A5 |
| 析构/移动的隐式联动 | 有析构的类移动被隐式删除：vector 扩容 `D(copy-only)` 复制 15 次 vs `C(noexcept move)` 移动 15 次 0 复制 | T4 |
| vector 扩容 | capacity 序列 1,2,4,8,16,32,64,128（2 倍），扩容搬移全部元素 | T4 |
| `-fdump-lang-class` 看 vptr | `class MA : public VA, public VB`（都多态）→ `sizeof=16`，两张子虚表（偏移 0 和 -8） | A3 |
| 多态对象的 vptr 数 | 多态对象里 vptr 个数 = **多态基类子对象个数**（继承不会「继承 vptr」，是构造时写入） | A3 |
| EBO | `sizeof(Empty)=1`、`EBO:Empty{int}=4`（基类可优化为 0 字节）、`NoEBO{Empty e;int}=8` | A3 |
| sizeof 不重排 | `class B:A`（char,short,long）实测 24，偏移 4/8/16，**没有「编译器优化重排」** | A3 |
| 声明虚析构 | 移动被隐式删除、多一个 vptr——「只要可能被继承就加虚析构」是过时建议 | T4/T5 |
| 去虚化 | `call_final(Sealed&)` 参数是引用，`-O2` 编译成 `movl $3,%eax` 完全消除 | A4/T5 |
| 构造函数调虚函数 | 不派发到派生类覆写（动态类型还是当前正在构造的类） | A4/T5 |
| ODR-use 陷阱 | 类内 `static const int k` 未 odr-use 能编译，取地址立刻链接错误 | A1 |
| 跨 TU 类型不一致 | `-flto -Wodr` 能抓到；不加 LTO 静默通过 = 最阴的 ODR 违规 | A1 |
| 位域 sizeof | `30+4+3` bits → 8；`30+:2+4+:0+3` → 12（与 README 一致，值得肯定） | A3 |
| `decltype` 类型 | `decltype(1)` = `int`（不是 `const int`）；`decltype("hello")` = `const char(&)[6]`；`decltype(Func(1))` 现代编译器 = `bool` | A4 |
| 宏 `#`/`##` | `STR(NAME)` 不展开；`XSTR(NAME)` 展开；`CAT` 的粘贴结果会被重新扫描展开 | 约定域 |
| 宏 `\` | `\` 后带空格 → 编译告警；规则是「\ 后不能有任何字符」 | 约定域 |
